Plugins Better GrokBot

Ein Plugin fügt auf der Registerkarte Plugins ein kleines Tool hinzu: einen Zähler, Standardantworten, einen Timer, einen Aufruf einer öffentlichen API ... Es ist in JavaScript in einer einzigen Datei geschrieben und wird als Paket geteilt.

Sicherheit geht vor

  • Jedes Plugin läuft in seinem eigenen Worker, isoliert von Grok und Better: keine Seite, kein DOM, keine lokale Bridge.
  • Vor Ihrem Code entfernt Better fetch, XMLHttpRequest, WebSocket, indexedDB, caches, importScripts und andere Netzwerk- und Speicherzugriffe.
  • Ein Plugin macht nur das, was sein plugin.json deklariert. Jede Anfrage durchläuft Better, wodurch die Berechtigung überprüft wird.
  • Nie zugänglich: API-Schlüssel, Token, Passwörter, Ihre Dateien, die Seite Grok, andere Plugins.
  • Ein Plugin, das nicht mehr reagiert (Endlosschleife) oder Fehler akkumuliert, wird gestoppt und deaktiviert. Wenn ein Start fehlschlägt, startet Better im abgesicherten Modus ohne Plugins neu.

Struktur eines Plugins

mon-outil/
  plugin.json   (obligatoire)
  main.js       (obligatoire)
  icon.png      (facultatif : png, svg, jpg ou webp, 96 Ko au plus)
  README.md     (facultatif)

Das Manifest plugin.json

{
  "manifest": 2,
  "id": "mon-outil",
  "name": "Mon outil",
  "version": "1.0.0",
  "description": "Ce que fait le plugin, en une phrase.",
  "author": "Votre nom ou pseudo",
  "icon": "🧩",
  "main": "main.js",
  "permissions": ["notify", "storage"],
  "hosts": [],
  "minVersion": "1.5.0",
  "homepage": "https://exemple.org"
}
Feld Herrscher
manifest Immer 2.
id Kleinbuchstaben, Zahlen und Bindestriche, ohne Bindestriche am Anfang oder Ende. Beispiel: mon-outil. Es muss einzigartig sein.
name Name angezeigt.
version Formatieren Sie 1.0.0. Eine höhere Version ersetzt beim Import die alte.
icon Ein Emoji oder der Name einer Bilddatei im Paket.
permissions Liste unter den unten aufgeführten. Es wird nichts anderes akzeptiert.
hosts Websites, die mit der Berechtigung net erreichbar sind (nur https).

Berechtigungen

Erlaubnis Was es erlaubt
notify Eine Benachrichtigung in Better (bg.ui.toast) anzeigen.
composer.read Lesen Sie den Text, den Sie in Grok eingeben.
composer.write Schreiben Sie in das Nachrichtenfeld von Grok, ohne es zu senden.
thread.read Lesen Sie das offene Gespräch.
storage Behalten Sie Ihre eigenen Daten (256 KB, isoliert von anderen Plugins).
clipboard.write Text in die Zwischenablage kopieren.
net Rufen Sie die in hosts aufgeführten Websites mit https auf. Lokale Adressen abgelehnt, 1 MB pro Antwort, ohne Cookies.

Fragen Sie so wenig wie möglich: Der Importbildschirm zeigt jede Berechtigung vor der Installation an.

Die bg-API

Ihr main.js erhält ein Objekt bg. Der Code kann await direkt verwenden.

bg.app            // { version, lang, locale }
bg.plugin         // { id, version, permissions }
bg.pick({ fr: "Bonjour", en: "Hello" })   // texte dans la langue de l'app

bg.ui.render([ ...éléments ])   // dessine le panneau
bg.ui.update("id", { text: "…" }) // modifie un élément qui a un id
bg.ui.badge("3")                 // petite pastille
await bg.ui.toast("Terminé")     // notify

await bg.composer.read()          // composer.read
await bg.composer.insert("texte") // composer.write
await bg.composer.replace("texte")// composer.write
await bg.thread.read()            // thread.read -> { agent, partial, messages: [{ role, text }] }
await bg.storage.get("clé")       // storage
await bg.storage.set("clé", valeur)
await bg.clipboard.write("texte") // clipboard.write
await bg.net.fetch("https://api.exemple.org/x", { method: "GET" }) // net -> { status, ok, type, text }
bg.on("open", () => {})           // le panneau devient visible
console.log("…")                  // visible dans la console du créateur

Schnittstellenelemente

Art Eigenschaften
title text
text text, tone (muted, good, bad)
button text, onClick, primary, disabled
input placeholder, value, onInput(valeur), onEnter(valeur)
textarea placeholder, value, rows, onInput(valeur)
toggle text, value, onChange(vrai/faux)
select options: [{ value, label }], value, onChange(valeur)
list items: [{ text, detail, value, onClick(value) }]
row children: [ … ] (in einer Zeile)
code text
progress value zwischen 0 und 1
image src in data:image/…;base64,…
badge, divider —

Jedes Element kann ein id haben, das von bg.ui.update verwendet wird.

Vollständiges Beispiel

// Compteur de mots (permission composer.read)
const t = bg.pick({ fr: "mots", en: "words" });
bg.ui.render([
  { type: "title", text: "Compteur" },
  { type: "text", id: "out", text: "…" },
]);
setInterval(async () => {
  const text = await bg.composer.read();
  const n = text.trim() ? text.trim().split(/\s+/).length : 0;
  bg.ui.update("out", { text: n + " " + t });
}, 1500);

Erstellen, testen, installieren

  1. Plugins > Plugin erstellen. Beginnen Sie mit einer Vorlage oder einer leeren Seite.
  2. Der Name füllt den Bezeichner selbst auf. Die Kontrolle erfolgt bei der Einreise.
  3. Überprüfen Sie die Berechtigungen, wählen Sie ein Symbol und schreiben Sie den Code.
  4. Test (Ctrl+Enter) startet das Plugin in der Vorschau mit seiner Konsole. Die Lagerung dort ist vorübergehend.
  5. Speichern und installieren, dann Jetzt neu starten: Plugins werden beim Start geladen.

Pakete: Import, Update, Export

  • Importieren: Ziehen Sie einen Plugin-Ordner, eine .zip oder eine .bgbplugin, auf das Fenster (Registerkarte Plugins geöffnet) oder verwenden Sie Ordner importieren / Archiv importieren.
  • Ein Paket kann ein Plugin (Root-Dateien) oder mehrere (ein Ordner pro Plugin) enthalten.
  • Better validiert jedes Manifest, zeigt die Berechtigungen und die Version (neu, aktualisiert, älter) an und fordert dann zur Bestätigung auf.
  • Update: Laden Sie eine höhere Version hoch. Das alte wird in plugins/.versions aufbewahrt.
  • Exportieren erstellt ein .zip, das zur Freigabe bereit ist. Entfernen verschiebt den Ordner nach plugins/.corbeille: Es wird nichts gelöscht.
  • Beschränkungen: 5 MB und 200 Dateien pro Paket; Erweiterungen .json .js .md .txt .css .svg .png .jpg .webp.

Best Practices

  • Nur eine Aufgabe pro Plugin, gut benannt.
  • Bitten Sie um die Mindestanzahl an Berechtigungen. Erkläre sie in der Beschreibung.
  • Übersetzen Sie Ihre Texte mit bg.pick.
  • Kein Timer schneller als nötig (eine Sekunde reicht fast immer).
  • Behalten Sie nur nützliche Daten und niemals Geheimnisse im Code.
  • Erhöhen Sie version mit jeder Veröffentlichung.

Fehlerbehebung

  • „ungültiger Bezeichner“: Verwenden Sie nur a-z, 0-9 und Bindestriche, zum Beispiel mon-outil.
  • „Berechtigung...nicht deklariert“: Fügen Sie es in permissions hinzu und installieren Sie es dann erneut.
  • „nicht deklarierter Host“: Fügen Sie die Domäne in hosts hinzu (mit der Berechtigung net).
  • Plugin wurde aus Sicherheitsgründen gestoppt: Es sind Fehler in einer Schleife aufgetreten oder es haben sich Fehler angesammelt. Beheben Sie das Problem und aktivieren Sie es dann erneut.
  • Abgesicherter Modus: Plugins > Abgesicherten Modus verlassen und dann neu starten.
