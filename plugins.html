Plugins Better GrokBot

Un plugin ajoute un petit outil dans l’onglet Plugins : un compteur, des réponses types, un minuteur, un appel à une API publique… Il s’écrit en JavaScript, en un seul fichier, et se partage sous forme de paquet.

Sécurité, d’abord

  • Chaque plugin tourne dans son propre Worker, isolé de Grok et de Better : pas de page, pas de DOM, pas de pont local.
  • Avant votre code, Better retire fetch, XMLHttpRequest, WebSocket, indexedDB, caches, importScripts et les autres accès au réseau et au stockage.
  • Un plugin ne fait que ce que déclare son plugin.json. Chaque demande passe par Better, qui vérifie la permission.
  • Jamais accessible : clés d’API, jetons, mots de passe, vos fichiers, la page de Grok, les autres plugins.
  • Un plugin qui ne répond plus (boucle infinie) ou qui accumule les erreurs est arrêté et désactivé. Si un démarrage échoue, Better redémarre en mode sans échec, sans aucun plugin.

Structure d’un plugin

mon-outil/
  plugin.json   (obligatoire)
  main.js       (obligatoire)
  icon.png      (facultatif : png, svg, jpg ou webp, 96 Ko au plus)
  README.md     (facultatif)

Le manifeste plugin.json

{
  "manifest": 2,
  "id": "mon-outil",
  "name": "Mon outil",
  "version": "1.0.0",
  "description": "Ce que fait le plugin, en une phrase.",
  "author": "Votre nom ou pseudo",
  "icon": "🧩",
  "main": "main.js",
  "permissions": ["notify", "storage"],
  "hosts": [],
  "minVersion": "1.5.0",
  "homepage": "https://exemple.org"
}
Champ Règle
manifest Toujours 2.
id Lettres minuscules, chiffres et tirets, sans tiret au début ni à la fin. Exemple : mon-outil. Il doit être unique.
name Nom affiché.
version Format 1.0.0. Une version plus haute remplace l’ancienne à l’import.
icon Un emoji, ou le nom d’un fichier image du paquet.
permissions Liste parmi celles ci-dessous. Rien d’autre n’est accepté.
hosts Sites joignables avec la permission net (https seulement).

Permissions

Permission Ce qu’elle permet
notify Afficher une notification dans Better (bg.ui.toast).
composer.read Lire le texte que vous tapez dans Grok.
composer.write Écrire dans le champ de message de Grok, sans l’envoyer.
thread.read Lire la conversation ouverte.
storage Garder ses propres données (256 Ko, isolées des autres plugins).
clipboard.write Copier du texte dans le presse-papiers.
net Appeler les sites listés dans hosts, en https. Adresses locales refusées, 1 Mo par réponse, sans cookies.

Demandez le moins possible : l’écran d’import montre chaque permission avant l’installation.

L’API bg

Votre main.js reçoit un objet bg. Le code peut utiliser await directement.

bg.app            // { version, lang, locale }
bg.plugin         // { id, version, permissions }
bg.pick({ fr: "Bonjour", en: "Hello" })   // texte dans la langue de l'app

bg.ui.render([ ...éléments ])   // dessine le panneau
bg.ui.update("id", { text: "…" }) // modifie un élément qui a un id
bg.ui.badge("3")                 // petite pastille
await bg.ui.toast("Terminé")     // notify

await bg.composer.read()          // composer.read
await bg.composer.insert("texte") // composer.write
await bg.composer.replace("texte")// composer.write
await bg.thread.read()            // thread.read -> { agent, partial, messages: [{ role, text }] }
await bg.storage.get("clé")       // storage
await bg.storage.set("clé", valeur)
await bg.clipboard.write("texte") // clipboard.write
await bg.net.fetch("https://api.exemple.org/x", { method: "GET" }) // net -> { status, ok, type, text }
bg.on("open", () => {})           // le panneau devient visible
console.log("…")                  // visible dans la console du créateur

Les éléments d’interface

Type Propriétés
title text
text text, tone (muted, good, bad)
button text, onClick, primary, disabled
input placeholder, value, onInput(valeur), onEnter(valeur)
textarea placeholder, value, rows, onInput(valeur)
toggle text, value, onChange(vrai/faux)
select options: [{ value, label }], value, onChange(valeur)
list items: [{ text, detail, value, onClick(value) }]
row children: [ … ] (sur une ligne)
code text
progress value entre 0 et 1
image src en data:image/…;base64,…
badge, divider —

Chaque élément peut avoir un id, utilisé par bg.ui.update.

Exemple complet

// Compteur de mots (permission composer.read)
const t = bg.pick({ fr: "mots", en: "words" });
bg.ui.render([
  { type: "title", text: "Compteur" },
  { type: "text", id: "out", text: "…" },
]);
setInterval(async () => {
  const text = await bg.composer.read();
  const n = text.trim() ? text.trim().split(/\s+/).length : 0;
  bg.ui.update("out", { text: n + " " + t });
}, 1500);

Créer, tester, installer

  1. Plugins > Créer un plugin. Partez d’un modèle ou d’une page vide.
  2. Le nom remplit l’identifiant tout seul. Il est vérifié pendant la saisie.
  3. Cochez les permissions, choisissez une icône, écrivez le code.
  4. Tester (Ctrl+Entrée) lance le plugin dans l’aperçu, avec sa console. Le stockage y est temporaire.
  5. Enregistrer et installer, puis Redémarrer maintenant : les plugins se chargent au démarrage.

Paquets : importer, mettre à jour, exporter

  • Importer : glissez un dossier de plugin, un .zip ou un .bgbplugin sur la fenêtre (onglet Plugins ouvert), ou utilisez Importer un dossier / Importer une archive.
  • Un paquet peut contenir un plugin (fichiers à la racine) ou plusieurs (un dossier par plugin).
  • Better valide chaque manifeste, montre les permissions et la version (nouveau, mise à jour, plus ancienne), puis demande confirmation.
  • Mise à jour : importez une version plus haute. L’ancienne est gardée dans plugins/.versions.
  • Exporter crée un .zip prêt à partager. Retirer déplace le dossier dans plugins/.corbeille : rien n’est effacé.
  • Limites : 5 Mo et 200 fichiers par paquet ; extensions .json .js .md .txt .css .svg .png .jpg .webp.

Bonnes pratiques

  • Une seule tâche par plugin, bien nommée.
  • Demandez le minimum de permissions ; expliquez-les dans la description.
  • Traduisez vos textes avec bg.pick.
  • Pas de minuterie plus rapide que nécessaire (une seconde suffit presque toujours).
  • Gardez les données utiles seulement, et jamais de secret dans le code.
  • Augmentez version à chaque publication.

Dépannage

  • « identifiant invalide » : utilisez seulement a-z, 0-9 et des tirets, par exemple mon-outil.
  • « permission … non déclarée » : ajoutez-la dans permissions, puis réinstallez.
  • « hôte non déclaré » : ajoutez le domaine dans hosts (avec la permission net).
  • Plugin arrêté par sécurité : il a bouclé ou cumulé les erreurs. Corrigez, puis réactivez-le.
  • Mode sans échec : Plugins > Quitter le mode sans échec, puis redémarrez.
