Plugins Better GrokBot

Wtyczka dodaje w zakładce Plugins małe narzędzie: licznik, standardowe odpowiedzi, timer, wywołanie publicznego API... Jest napisany w JavaScript, w jednym pliku i udostępniany jako pakiet.

Bezpieczeństwo przede wszystkim

  • Każda wtyczka działa we własnym Worker, odizolowanym od Grok i Better: bez strony, bez DOM, bez lokalnego mostu.
  • Przed kodem Better usuwa fetch, XMLHttpRequest, WebSocket, indexedDB, caches, importScripts oraz inny dostęp do sieci i pamięci.
  • Wtyczka robi tylko to, co deklaruje jej plugin.json. Każde żądanie przechodzi przez Better, który sprawdza uprawnienia.
  • Nigdy niedostępne: klucze API, tokeny, hasła, Twoje pliki, strona Grok, inne wtyczki.
  • Wtyczka, która już nie odpowiada (nieskończona pętla) lub gromadzi błędy, jest zatrzymywana i dezaktywowana. Jeśli uruchomienie się nie powiedzie, Better uruchomi się ponownie w trybie awaryjnym, bez żadnych wtyczek.

Struktura wtyczki

mon-outil/
  plugin.json   (obligatoire)
  main.js       (obligatoire)
  icon.png      (facultatif : png, svg, jpg ou webp, 96 Ko au plus)
  README.md     (facultatif)

Manifest plugin.json

{
  "manifest": 2,
  "id": "mon-outil",
  "name": "Mon outil",
  "version": "1.0.0",
  "description": "Ce que fait le plugin, en une phrase.",
  "author": "Votre nom ou pseudo",
  "icon": "🧩",
  "main": "main.js",
  "permissions": ["notify", "storage"],
  "hosts": [],
  "minVersion": "1.5.0",
  "homepage": "https://exemple.org"
}
Pole Linijka
manifest Zawsze 2.
id Małe litery, cyfry i łączniki, bez łączników na początku i na końcu. Przykład: mon-outil. To musi być wyjątkowe.
name Wyświetlana nazwa.
version Sformatuj 1.0.0. Wyższa wersja zastępuje starą po imporcie.
icon Emoji lub nazwa pliku obrazu w pakiecie.
permissions Wypisz spośród poniższych. Nic innego nie jest akceptowane.
hosts Witryny dostępne po uzyskaniu pozwolenia net (tylko https).

Uprawnienia

Pozwolenie Na co pozwala
notify Pokaż powiadomienie w Better (bg.ui.toast).
composer.read Przeczytaj tekst, który wpisujesz w polu Grok.
composer.write Napisz w polu wiadomości Grok, bez wysyłania.
thread.read Przeczytaj otwartą rozmowę.
storage Zachowaj własne dane (256 KB, odizolowane od innych wtyczek).
clipboard.write Skopiuj tekst do schowka.
net Zadzwoń do witryn wymienionych w hosts, używając protokołu https. Adresy lokalne odrzucone, 1 MB na odpowiedź, bez plików cookie.

Pytaj jak najmniej: ekran importu pokazuje każde pozwolenie przed instalacją.

Interfejs API bg

Twój main.js otrzymuje obiekt bg. Kod może bezpośrednio używać await.

bg.app            // { version, lang, locale }
bg.plugin         // { id, version, permissions }
bg.pick({ fr: "Bonjour", en: "Hello" })   // texte dans la langue de l'app

bg.ui.render([ ...éléments ])   // dessine le panneau
bg.ui.update("id", { text: "…" }) // modifie un élément qui a un id
bg.ui.badge("3")                 // petite pastille
await bg.ui.toast("Terminé")     // notify

await bg.composer.read()          // composer.read
await bg.composer.insert("texte") // composer.write
await bg.composer.replace("texte")// composer.write
await bg.thread.read()            // thread.read -> { agent, partial, messages: [{ role, text }] }
await bg.storage.get("clé")       // storage
await bg.storage.set("clé", valeur)
await bg.clipboard.write("texte") // clipboard.write
await bg.net.fetch("https://api.exemple.org/x", { method: "GET" }) // net -> { status, ok, type, text }
bg.on("open", () => {})           // le panneau devient visible
console.log("…")                  // visible dans la console du créateur

Elementy interfejsu

Uprzejmy Właściwości
title text
text text, tone (muted, good, bad)
button text, onClick, primary, disabled
input placeholder, value, onInput(valeur), onEnter(valeur)
textarea placeholder, value, rows, onInput(valeur)
toggle text, value, onChange(vrai/faux)
select options: [{ value, label }], value, onChange(valeur)

progress value od 0 do 1

badge, divider —

Każdy element może mieć id, używany przez bg.ui.update.

Kompletny przykład

// Compteur de mots (permission composer.read)
const t = bg.pick({ fr: "mots", en: "words" });
bg.ui.render([
  { type: "title", text: "Compteur" },
  { type: "text", id: "out", text: "…" },
]);
setInterval(async () => {
  const text = await bg.composer.read();
  const n = text.trim() ? text.trim().split(/\s+/).length : 0;
  bg.ui.update("out", { text: n + " " + t });
}, 1500);

Twórz, testuj, instaluj

  1. Plugins > Utwórz wtyczkę. Zacznij od szablonu lub pustej strony.
  2. Nazwa sama wypełnia identyfikator. Jest to sprawdzane podczas wejścia.
  3. Sprawdź uprawnienia, wybierz ikonę, napisz kod.
  4. Test (Ctrl+Enter) uruchamia wtyczkę w podglądzie wraz z konsolą. Przechowywanie tam jest tymczasowe.
  5. Zapisz i zainstaluj, a następnie Uruchom ponownie teraz: wtyczki ładują się przy uruchomieniu.

Pakiety: import, aktualizacja, eksport

  • Importuj: przeciągnij folder wtyczki, .zip lub .bgbplugin do okna (otwarta karta Plugins) lub użyj opcji Importuj folder / Importuj archiwum.
  • Pakiet może zawierać jedną wtyczkę (pliki root) lub kilka (jeden folder na wtyczkę).
  • Better sprawdza każdy manifest, pokazuje uprawnienia i wersję (nową, zaktualizowaną, starszą), a następnie prosi o potwierdzenie.
  • Aktualizacja: Prześlij wyższą wersję. Stary jest przechowywany w plugins/.versions.
  • Eksport tworzy plik .zip gotowy do udostępnienia. Usuń przenosi folder do plugins/.corbeille: nic nie jest usuwane.
  • Limity: 5 MB i 200 plików w pakiecie; rozszerzenia .json .js .md .txt .css .svg .png .jpg .webp.

Najlepsze praktyki

  • Tylko jedno zadanie na wtyczkę, dobrze nazwane.
  • Zapytaj o minimalną liczbę uprawnień; wyjaśnij je w opisie.
  • Tłumacz swoje teksty za pomocą bg.pick.
  • Żaden timer nie będzie szybszy niż to konieczne (jedna sekunda prawie zawsze wystarczy).
  • Przechowuj tylko przydatne dane, a nigdy tajemnice w kodzie.
  • Zwiększaj version z każdą publikacją.

Rozwiązywanie problemów

  • „nieprawidłowy identyfikator”: Używaj tylko a-z, 0-9 i łączników, na przykład mon-outil.
  • „zezwolenie… niezadeklarowane”: dodaj je w permissions, a następnie zainstaluj ponownie.
  • „niezadeklarowany host”: dodaj domenę w hosts (z uprawnieniami net).
  • Wtyczka zatrzymana ze względów bezpieczeństwa: zapętliła się lub zgromadziła błędy. Napraw to, a następnie włącz ponownie.
  • Tryb awaryjny: Plugins > Wyjdź z trybu awaryjnego, a następnie uruchom ponownie.
